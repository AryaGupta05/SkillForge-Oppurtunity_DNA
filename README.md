# Opportunity DNA

**Opportunity DNA** is a production-quality MVP designed to replace traditional, resume-centric candidate evaluation with a dynamic, evidence-based capability profile.

Instead of relying primarily on pedigree (such as college prestige, GPA, or previous employer name) or simple keyword matching, Opportunity DNA analyzes candidate evidence—including resumes, projects, GitHub repositories, certifications, hackathons, portfolios, and assessments—to identify demonstrated, inferred, and adjacent skills.

The platform transforms this evidence into an **Opportunity DNA profile** that can be used for skill mapping, internship and placement matching, skill-gap analysis, readiness assessment, and personalized development recommendations.

This project was developed under the **Smart India Hackathon (SIH) 2026 Problem Statement SIH26044**:

> **"Portal for Academia - Industry collaboration for Skill Mapping, Internships and Placement"**

---

## Key Features

### 1. **Evidence-Based Skill Profiles**

Every identified skill is linked to supporting evidence such as:

- Projects
- GitHub repositories
- Resumes
- Certifications
- Hackathons
- Portfolios
- Assessments

Skills are not treated as unexplained AI-generated labels. The system maintains traceability between a capability and the evidence supporting it.

---

### 2. **Opportunity DNA**

Opportunity DNA creates a dynamic capability profile based on:

- Identified skills
- Skill confidence
- Proficiency level
- Evidence strength
- Project experience
- Learning progression
- Demonstrated capabilities

This allows a student's profile to evolve as they add new projects, certifications, assessments, and other evidence.

---

### 3. **Skills-First Internship & Placement Matching**

Traditional resume keyword matching is replaced with capability-based matching.

Opportunities can specify:

- Required skills
- Required proficiency
- Skill importance
- Location preferences
- Sector/industry
- Academic or eligibility requirements

The matching engine evaluates the candidate's demonstrated capabilities against the requirements and produces an explainable compatibility score.

---

### 4. **Explainable Recommendations**

Every recommendation can be explained through the candidate's underlying evidence and capability profile.

Instead of simply showing:

> "92% Match"

the system can explain:

- Which skills matched
- The candidate's proficiency
- Supporting evidence
- Missing or weaker skills
- Why the opportunity was recommended

This makes recommendations more transparent and actionable.

---
